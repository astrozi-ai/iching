# iching

**Shared primitives for Chinese metaphysics in TypeScript — by [AstroZi](https://astrozi.ai)**

Stems and branches (干支), five phases (五行), solar terms (节气) and explicit time conventions: the common ground that BaZi, Zi Wei Dou Shu and Liu Yao calculations build on. Every convention is stated explicitly, so the same input always gives the same result.

> **Status: pre-release.** The package is reserved and the API is not published yet.

| --- | --- | --- |
| [`@iching/core`](packages/core) | 干支 · 五行 · 节气 · time conventions | planned |
